# Chat

Native SwiftUI app that uses Apple Foundation Models to provide on-device chat across iPhone, iPad, and Mac.

## Build

1. Open the project in Xcode.
2. Select the app target and your destination device or simulator.
3. Build and run with `Product > Run` or `Cmd+R`.

## Requirements

- Xcode with Foundation Models support
- A supported OS version for the selected target
- For model-backed chat features: an Apple Intelligence-capable device with the necessary system features enabled
